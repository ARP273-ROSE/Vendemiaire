Polices embarquées / Embedded fonts
===================================

Fournies avec le programme pour que l'interface garde le même aspect sur tous
les ordinateurs, quels que soient le thème, les polices ou la langue du
système. / Shipped with the program so that the interface looks the same on
every computer, whatever the system's theme, fonts or language.
